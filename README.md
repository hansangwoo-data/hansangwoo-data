## Featured Projects

### 1. [Synthetic Global Collectible RPG Analytics](https://github.com/hansangwoo-data/Synthetic-Global-Collectible-RPG-Analytics)

An end-to-end analytics project based on a fully fictional global collectible RPG scenario.

- Built a synthetic analytics dataset with **6 analysis tables totaling 27,351 rows**, with explicit table grain and validation criteria
- Applied **81 automated tests** to check data quality, integrity, and analysis logic
- Analyzed lifecycle, retention, PvE participation, monetization, incident recovery, and regional strategy
- Connected data generation → quality assurance → analysis → visualization → recommendations
- Used **Python, pandas, SQL, and automated testing**

Selected scenario findings include a normal boss participation index of **82.17 (reference 100)** during the Astra collaboration, adjacent-offer revenue per paying user per day declining **13.32% in the 14-day post-launch period**, and returned users reaching **293.95% of the pre-incident baseline** during the compensation period while revenue recovered to only **56.19%**.

> All data, events, products, timelines, and service incidents in this project are independently designed and synthetic. No proprietary company or player data is included.

### 2. [SQL E-commerce Revenue Analysis](https://github.com/hansangwoo-data/ecommerce-revenue-analysis-sql)

An analysis of purchase behavior and revenue drivers using BigQuery's public `thelook_ecommerce` dataset.

- Compared first completed orders with subsequent completed repeat orders
- Examined category-level revenue structures and price segments
- Used **BigQuery SQL** for extraction and aggregation
- Used **Python and pandas** for visualization and interpretation
- Defined metric scope and validated source data against aggregated results using SQL

The analysis compared first-order and repeat-order behavior, category-level revenue, and price segments while validating metric definitions against source data.
